最先要证明的是轨迹形态能否被稳定识别；随后才是摄像头端的跟踪质量、未知样本拒识和日级趋势。公开数据可支撑前两步的研究基准，但不能替代真实居家场景和目标人群上的合规验证。

01 / 数据集

按“任务匹配度”选择数据，而不是按名字堆数据

前两个为原技术路线中的核心参考；第三个是实际落地必须补齐的目标域数据。公开数据用于模型基准与方法比较，授权实拍数据才用于评估摄像头场景中的真实可用性。

WanderingPatterns

四分类主数据

按方案材料：约 1,600 条轨迹、4 类（direct / pacing / lapping / random）、每类约 400 条、长度 80。

  • 用途：四分类监督、形态特征分析、自监督预训练、消融实验。
  • 适配点：与目标的三类徘徊样形态 + direct 对照直接对应。
  • 限制：先核验参与者 ID 是否可用；无法确认时，仅称为轨迹级 shape benchmark。
来源：Ramos-Rivera et al., 2024

SmartCare

二分类补充

按方案材料：200 条训练池轨迹 + 20 条官方验证轨迹，主要提供“徘徊 / 非徘徊”二分类监督。

  • 用途：训练第一层 direct 与 wandering-like 判别头。
  • 适配点：可避免把二分类样本伪造为 pacing/lapping/random 子类型。
  • 限制：缺少可靠逐点时间信息；20 条官方验证集在阈值/方案冻结前不得使用。
来源：SmartCare, 2021

授权居家视频轨迹集

目标域必需

由项目在用户授权和最小必要采集前提下建设：固定摄像头视频、检测/跟踪轨迹、房间/时段元数据、人工复核记录。

  • 用途：Camera QC、可用窗口比例、端到端误报/漏报、日级趋势与人工复核一致性。
  • 最小设计：客厅/通道等固定场景、日夜时段、短遮挡/漏点/ID 切换等故障标签。
  • 注意：去标识化、访问控制、保留周期和数据授权需先于采集确定。
来源：项目自建；不可用公开轨迹或合成污染替代。
02 / 方法清单

从最小可行基线开始，再逐步增加复杂度

下面的方法不是要求全部一次性实现，而是给出与原技术路线对应的可选工具。标为“首期”的应优先完成；“增强”仅在基线与数据质量已验证后加入。

方法解决的问题在本方案中的具体用法优先级
轨迹质量控制（QC）长缺口、瞬移、ID 切换、跨视频拼接、相机移动会产生伪运动。先规则门控，再进入分类器；严重故障输出 unavailable，不靠平滑掩盖。首期必做
无锚点形状归一化不同画布、人物远近、朝向和轻度透视造成域差异。中位数去平移，以横纵跨度的单一尺度归一化；保留长宽比，不声称恢复真实米制坐标。首期必做
手工特征 + Random Forest建立低门槛、可解释且可快速复现的强基线。路径长度、净位移、路径效率、转角、曲率、反向次数、回访距离、覆盖面积等。首期必做
TCN（时序卷积网络）提取局部位移、转向和往返模式，训练成本低于重型 Transformer。作为纯深度基线，也作为 TopoWander-MPT 的局部编码器。首期必做
分层分类同时利用四分类数据和仅有二分类标签的数据。头 1：direct vs wandering-like；头 2：仅对 wandering-like 判 pacing/lapping/random。首期必做
语义 patch + 关系偏置 Transformer识别相隔较远的回访、反向与闭合关系，降低小样本纯注意力学习难度。把路径效率、回访、覆盖面积等 patch 特征及片段间空间/时间关系编码为注意力偏置。增强实现
投影与观测污染模拟公开轨迹与摄像头轨迹的输入分布不一致。随机旋转、缩放、轻度透视、裁切、抖动、漏点、底边偏移；记录种子与参数以便重放。增强实现
掩码自监督预训练标签小、模型易过拟合。遮挡局部 patch，重建位移、转角、曲率、路径效率与回访关系；仅在训练划分中执行。增强实现
温度缩放 + 原型/能量 OOD闭集分类器会对未知形态过度自信。在验证集校准概率；将低质样本输出 unavailable，质量合格但未知样本输出 uncertain。增强实现
窗口合并 + 个人基线单个 40 秒窗口不应直接形成风险结论。合并连续窗口为片段，统计日级频次、时长、夜间比例与类型分布，再与个人历史基线比较。接入阶段
03 / 建议组合

一条可实现、可答辩的最小算法路径

推荐实施顺序

1
安全转换与数据划分原始数据只读，记录哈希、字段统计和异常；先划分再切窗/增强。
数据
2
QC + 形状归一化 + RF 基线用最短链路验证数据、形态特征、错误拒绝与评估脚本。
基线
3
纯 TCN + 分层分类验证深度时序表征对 Random Forest 的真实增益。
模型
4
TopoWander-MPT + 污染模拟仅在前两步结果可信时加入运动语义、关系偏置和一致性训练。
增强
5
校准/拒识 + 日级基线不确定则拒绝判断；最终只输出行为证据与复核建议。
接入

核心表达式

center = median(points) span_x = Q95(x) - Q05(x) span_y = Q95(y) - Q05(y) scale = sqrt(span_x² + span_y²) qᵢ = (pᵢ - center) / max(scale, ε) P(direct) = 1 - P(wandering) P(pacing) = P(wandering) × P(pacing | wandering) P(lapping) = P(wandering) × P(lapping | wandering) P(random) = P(wandering) × P(random | wandering)

上半部分是形状适配：消除平移并以同一尺度保留长宽比。下半部分是分层分类：让二分类数据只监督它实际具备的标签。

05 / 使用原则

把引用和数据使用写进研究设计，而不是放在文末

数据

训练、验证、测试严格分隔

同一参与者、会话、原始轨迹以及其切窗/增强视图不得跨集合；记录原始文件哈希、转换器版本、读写和拒绝样本数。

结论

按证据等级表述

公开轨迹结果 = 基准能力；模拟污染结果 = 鲁棒性压力测试；授权实拍结果 = 目标摄像头可用性；三者不可混写。

边界

不将轨迹等同于诊断

同样的往返可能来自找物品、锻炼或打电话。输出只能是行为形态、趋势与复核建议，不能给出疾病诊断或医学风险等级。

每一个外部数据源先确认许可、获取方式与再分发限制
每个论文方法都配一个可验证的消融或对照实验
把 uncertain / unavailable 纳入产品状态与测试指标
真实视频只在授权、脱敏和访问控制落实后使用
