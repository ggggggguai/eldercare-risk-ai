项目环境参考
============

本文档记录本机已经验证过的开发环境，供中文开发者复现和排查环境问题使用。
标准环境定义以 `environment.yml` 为准。

Conda 环境
----------

环境名称：

  eldercare-ai

Conda channel：

  conda-forge

已验证 Python 版本：

  Python 3.11.15

创建或更新环境
--------------

从零创建环境：

  /Users/guai/miniforge3/bin/mamba env create -f environment.yml

更新已有环境：

  /Users/guai/miniforge3/bin/mamba env update -n eldercare-ai -f environment.yml

激活环境：

  source /Users/guai/miniforge3/bin/activate eldercare-ai

验证项目：

  conda run -n eldercare-ai python -m pytest -q

说明
----

- `environment.yml` 是重建项目环境的唯一标准来源。
- `pyproject.toml` 定义 Python 包元数据和可选依赖组。
- 标准环境显式安装发行包 `torch==2.13.0`；目标 Linux wheel 的运行时 `torch.__version__` 为 `2.13.0+cu130`，不再依赖 `ultralytics` 间接解析版本。
- 本文件不是完整锁文件，因为传递依赖可能因平台而变化。
- 徘徊步骤 10 的 Linux/x86_64 runtime 事实源为：

  configs/runtime/wandering_step10_runtime_v1.yml

- 该文件使用 27 个具体 Conda 工件 URL/MD5 锁定 Python、pip、OpenSSL、libgcc、libstdc++、packaging、setuptools、wheel 等完整 Conda 集合，并使用 30 个具体 wheel URL/SHA-256 锁定 PyTorch、NumPy、PyYAML 及 PyTorch 的 pip 传递依赖；原始字节为 11426 bytes，SHA-256 为：

  034d603ae722e1723189e03fbab05a3e8c110809d0f49011ef3e9ece8e2f1cda

- 从仓库根目录重建独立验证环境：

  conda env create -n eldercare-ai-wandering-runtime-v1-rebuild -f configs/runtime/wandering_step10_runtime_v1.yml

- 该专用事实源只冻结步骤 10 所需的 Linux/x86_64 Python/Torch/NumPy/PyYAML runtime，不替代完整开发环境的 `environment.yml`，也不绑定项目源码；步骤 10 另行校验源码与配置 SHA。候选 commit `03079a5` 已由此前不存在的全新 checkout/环境复验，状态为 `wandering_step10_runtime_fact_source_verified`。
