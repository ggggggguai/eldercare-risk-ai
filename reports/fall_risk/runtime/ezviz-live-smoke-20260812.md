# 萤石真实直播算法端烟测（2026-08-12）

## 结论

授权萤石开放平台 HTTPS-FLV 直播在修复后的 FFmpeg 服务链上通过 120 秒严格算法端烟测。传输保持单一 stream epoch，姿态、步态、坐站、近跌倒和跌倒状态分支均形成有效窗口，停止线程在预算内退出。该结果证明当前机器与当前直播地址能够运行算法工程链，不证明跌倒识别准确率、临床有效性、业务后端回调、地址刷新、弱网恢复或一小时资源验收。

完整脱敏机器报告位于本机临时文件 `/tmp/ezviz_live_smoke_20260812_final.json`，不纳入仓库。报告和本文均不包含设备序列号、直播路径、查询签名、Token 或原始帧。

## 本次修复

- 增加 FFmpeg/ffprobe 后端与容器依赖、readiness 检查和有界停止。
- 解码器错误脱敏直播地址，避免状态接口泄露临时签名。
- 短连接只有达到稳定时长或帧数后才重置重连预算，避免有限短流永久重连。
- URL 在旧连接打开期间更新时会丢弃过期连接；并发回归已覆盖，真实萤石地址在线刷新仍待端到端验收。
- FFmpeg 限帧只选择原始帧，不补造低帧率重复帧。
- 服务默认使用 FFmpeg、640 解码宽度、640 姿态输入和 10 FPS 调度上限。
- 严格烟测要求四个关键分支在测试周期内达到 `valid`，并保留全程状态集合，避免用收尾瞬时窗口覆盖长期证据。

## 剩余验收

1. 使用业务后端真实 callback endpoint 验证鉴权、`event_id` 幂等和终止版本处理。
2. 在会话运行中刷新一次临时直播地址，确认 session ID 不变、epoch 隔离且继续出帧。
3. 执行弱网断连/恢复和过期 URL 故障注入。
4. 在固定部署硬件上运行至少一小时，记录 CPU、内存、温度、队列丢帧、分阶段延迟和有效采样率。
5. 使用人工标注动作验证误报/漏报；本烟测不构成算法效果证据。
