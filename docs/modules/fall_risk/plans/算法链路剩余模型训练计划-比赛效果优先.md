# 算法链路剩余模型训练计划：比赛效果优先

> 日期：2026-08-10
> 目标比赛：挑战杯揭榜挂帅赛题 `XH-202617`
> 计划范围：步态稳定性、坐站转换、个体行为基线、跌倒风险融合
> 计划原则：优先提升可验证的模型效果和比赛表达，不以服务化、接口、部署或工程完备度为主要目标

## 1. 结论先行

后续不应继续重复训练已经达到较高候选窗口指标的跌倒 TCN，而应集中解决算法链路中决定“前置风险识别”能力的四个模型：

1. 重做步态稳定性模型，将当前不可用的低精度 TCN 提升为可展示的功能风险分支。
2. 将坐站模型从预裁剪动作分类升级为连续坐站事件与能力特征识别。
3. 用连续个人数据训练或标定个体行为基线，使系统能够识别“这个老人相对自己变差了”。
4. 用配对风险标签训练轻量融合模型，证明步态、坐站、近跌倒和个人基线组合后优于单纯跌倒检测。

比赛主模型不追求网络越大越好。步态和坐站以轻量时序模型为主，个体基线以稳健时序统计为主，风险融合以 EBM/LightGBM 为主。ST-GCN++、MS-TCN++ 和时序自编码器只作为能证明增益的增强对照。

当前最大阻塞不是算力，而是有效监督：步态 validation 只有 12 个正动作段，坐站高分高度集中于 NTU，`risk_labels.jsonl` 当前为 0 条。继续在原数据上堆网络或 epoch，难以形成可信的比赛提升。

## 2. 比赛要求如何映射到模型训练

[比赛方案](../../../reference/competition/XH-202617-基于多模态AI监测的老年人跌倒风险、心理健康、诈骗识别及预警研究比赛方案.pdf)明确要求：

- 跌倒风险研究要区别于跌倒动作识别，体现从事后识别向前置防控升级。
- 作品核心指标是风险识别准确率，必须有居家典型场景实测数据支撑。
- 初审“研发思路与创新性”占 30 分，“技术有效性与性能合理性”占 20 分。
- 终审“识别精准性与响应效能”占 30 分，要求准确率、召回率、误报率等关键指标表现和结果可复现。
- 高分作品需要体现前置预判、连续感知或分级干预，而不是只展示一次跌倒动作分类。

因此，本计划把比赛模型证据组织为三层：

```text
即时事件层：已训练的近跌倒 TCN + 跌倒 TCN
功能变化层：待提升的步态模型 + 待升级的坐站模型
前置风险层：待训练的个人基线 + 待训练的风险融合模型
```

官方方案没有规定必须达到某个固定准确率。本文后续数值均为项目内部冲奖目标，不是赛事硬性及格线。由于高风险样本不平衡，只报告 Accuracy 会掩盖漏报；比赛材料必须同时展示 Recall、Precision、F1、PR-AUC、误报率和分场景结果。

## 3. 当前模型效果基线

| 模型分支 | 当前结果 | 主要问题 | 本计划定位 |
|---|---|---|---|
| 跌倒动作 TCN | 三 seed 集成 validation F1 `0.9739`、Recall `0.9699` | 仍是 4 秒候选窗口分类 | 冻结为即时事件输入，不重复调参 |
| 近跌倒 TCN | 三 seed 事件 F1 `0.9933-0.9967` | validation 负例种类过窄 | 冻结为前置事件输入，补困难负例复评 |
| 步态 TCN | 六 seed 集成 F1 `0.308`、Recall `0.500`、误报约 `40.8/小时` | validation 仅 12 个正动作段，模型效果不可用 | 本计划第一优先级 |
| 坐站 TCN | 候选 clip F1 `0.986`，但 Fall Detection 2017 F1 `0.545` | 总体分数被 NTU 主导，不能定位连续事件 | 本计划第二优先级 |
| 个体基线 | 滚动均值/标准差/分位数规则 | 无长期个体标定和变化真值 | 本计划第三优先级 |
| 风险融合 | 固定权重规则评分卡 | 没有监督训练，无法证明融合增益 | 本计划最终主实验 |

现有跌倒结果见[跌倒识别 TCN 三 seed 集成实验](../../../../reports/fall_risk/fall_event_proxy_v1/README.md)，近跌倒结果见[近跌倒恢复确认 TCN 报告](../../../../reports/fall_risk/near_fall_event_v1/README.md)。

## 4. 总体训练路线

### 4.1 统一输入

四类模型共享下列上游结果，但分别训练和评价：

- 姿态序列：关节坐标、速度、加速度、骨向量、关键点质量和缺失 mask。
- 步态分支：步频、速度 proxy、左右对称性、髋部横摆、停顿和转身稳定性。
- 坐站分支：动作方向、持续时间、髋部垂直位移、躯干倾角、失败尝试和稳定时间。
- 事件分支：近跌倒分数、跌倒分数、事件频率和最近一次事件间隔。
- 个体分支：个人历史中位数、MAD、趋势、变点和相对偏离。
- 上下文：场景、活动节律、时间段和输入质量。

### 4.2 模型选型原则

| 任务 | 必做 baseline | 主模型 | 增强对照 | 不优先方案 |
|---|---|---|---|---|
| 步态稳定性 | 规则、EBM/LightGBM | 多任务轻量 TCN | ST-GCN++ | 大型 Transformer |
| 坐站转换 | 状态机、Logistic | 多头 MS-TCN++ 或因果 TCN | ST-GCN++/PoseC3D | 只做整段 clip 分类 |
| 个体基线 | 群体阈值、Median/MAD | EWMA/CUSUM + 混合效应基线 | 时序自编码器 | 无纵向数据时训练深度异常模型 |
| 风险融合 | 现有规则评分卡、Logistic | EBM 或 LightGBM | 小型缺失感知 MLP | Risk Fusion Transformer |

### 4.3 统一训练约束

- 每种主模型至少运行 seed `42/43/44`，报告均值、标准差和最佳单模型，不只展示最优 seed。
- 所有模型按人员或保守来源组划分，禁止同一人的相邻窗口跨训练和验证。
- 模型选择以 validation 为准，最终 test 只运行一次；比赛表格同时给出 validation 和 test。
- 主指标优先采用事件级或人员日级结果，窗口级 accuracy 只用于诊断。
- 选择模型时先满足 Recall 和误报上限，再比较 F1/PR-AUC；不能通过极低阈值换取表面高 Recall。
- 除总体指标外，必须报告最差数据源、最差场景和最差动作类型。

## 5. 模型一：步态稳定性模型

### 5.1 训练目标

识别持续性步态不稳定、拖步、左右不对称、速度明显下降和转身不稳，输出 `gait_risk_score`。目标不是诊断疾病，而是为前置跌倒风险提供可重复的功能变化证据。

### 5.2 当前问题

- 现有 validation 只有 12 个正动作段，F1 对单个样本极其敏感。
- 当前 TCN Recall 只有 `0.500`，不能作为风险前置分支。
- 正负类别与数据来源可能相关，模型容易学习数据集风格而非步态特征。
- 当前训练产物未保留在工作区，后续需要重新生成完整 checkpoint。

### 5.3 数据补强重点

优先补充以下动作，而不是继续切更多相邻窗口：

- 慢走、拖步、步宽异常、左右不对称、短步和转身不稳。
- 正常慢走、正常转身、短暂停顿、弯腰、坐下和使用助行器等困难负例。
- 老人或模拟功能受限人群的正面、侧面、斜侧和高位视角。
- 客厅、卧室通道和普通 home 场景的连续行走片段。

在计算正式效果前，validation 和 test 各至少需要 50 个独立正动作段，并覆盖多个受试者或保守来源组；否则只报告探索性结果和置信区间，不把单一 F1 当作稳定效果。

### 5.4 实验矩阵

| 实验 | 模型 | 目的 |
|---|---|---|
| G0 | 当前规则步态分 | 建立可解释下限 |
| G1 | EBM/LightGBM + 人工步态特征 | 判断小样本下结构化特征上限 |
| G2 | 现有 TCN v5 复现 | 固定历史对照 |
| G3 | TCN + 动作预训练 + focal loss + 分组均衡采样 | 提高少数类召回并抑制来源偏差 |
| G4 | joint/bone/motion 三流 ST-GCN++ | 验证骨架拓扑是否带来真实增益 |
| G5 | G3 与 G4 概率集成 | 仅在错误互补时保留 |

G3 作为主模型。G4 首先只训练一个 seed；若相对 G3 的 PR-AUC 或最差来源 F1 没有至少 3 个百分点提升，则停止继续训练其余 seed。

### 5.5 内部冲奖目标

| 指标 | 最低保留线 | 冲奖目标 |
|---|---:|---:|
| 事件级 Recall | `>= 0.80` | `>= 0.90` |
| 事件级 F1 | `>= 0.65` | `>= 0.75` |
| PR-AUC | `>= 0.70` | `>= 0.80` |
| Balanced accuracy | `>= 0.75` | `>= 0.85` |
| 最差来源 F1 | `>= 0.55` | `>= 0.70` |
| 连续正常片段误报 | `< 10/小时` | `< 3/小时` |

如果补充数据后仍无法达到最低保留线，比赛主链保留 EBM/规则，不把深度步态模型作为核心创新点。

### 5.6 必做消融

- 去掉动作预训练。
- 去掉 walking gate。
- 去掉 joint-motion 或 bone-motion。
- 去掉质量 mask。
- TCN 与 ST-GCN++ 在完全相同输入上的对照。
- 按老人域、视角、场景和助行器分别统计。

## 6. 模型二：坐站转换模型

本节的具体实施顺序、文件级产物、数据门禁、测试要求和 Codex 停止条件，见[坐站模型训练计划：Codex 执行任务书](坐站模型训练计划-Codex执行任务书.md)。该任务书以连续事件定位为主线，当前候选 clip TCN 只作为 provisional 历史对照。

### 6.1 训练目标

从连续姿态中定位坐下和起立的 onset/offset，输出方向、持续时间、失败尝试次数、躯干代偿和稳定时间。比赛价值是把“坐站能力下降”作为跌倒前功能风险，而不是只判断视频片段里有没有坐站动作。

### 6.2 当前问题

- 当前 F1 `0.986` 来自预裁剪候选 clip，总体样本高度集中于 NTU。
- Fall Detection 2017 分来源 F1 只有 `0.545`，存在明显跨来源下降。
- 当前模型没有逐帧相位和真实边界监督，无法给出起止误差、持续时间或失败尝试。
- 历史训练报告存在，但 checkpoint 当前不在工作区。

### 6.3 数据补强重点

- 对连续视频标注 `sit_start/sit_end/stand_start/stand_end`。
- 标注完整、犹豫、中断、失败重试和扶物完成等状态。
- 加入弯腰、蹲下、跪地、捡物、跌倒和快速坐下等困难负例。
- 保证客厅沙发、卧室床边、卫生间坐便器附近至少各有独立验证样本。

### 6.4 实验矩阵

| 实验 | 模型 | 目的 |
|---|---|---|
| S0 | 当前状态机 | 连续事件定位 baseline |
| S1 | 结构化 Logistic | 验证人工特征可分性 |
| S2 | 当前 candidate TCN | 固定 clip 分类上限 |
| S3 | 多头因果 TCN | 同时预测帧相位、事件方向和完成质量 |
| S4 | MS-TCN++ | 降低相位碎片和边界抖动 |
| S5 | ST-GCN++ | 验证关节拓扑对扶物、躯干代偿的增益 |

S3/S4 二选一作为主模型。选择依据不是 clip F1，而是事件 F1、边界误差和跨来源最差表现。

### 6.5 内部冲奖目标

| 指标 | 最低保留线 | 冲奖目标 |
|---|---:|---:|
| 坐站事件 Recall | `>= 0.85` | `>= 0.92` |
| 坐站事件 F1 | `>= 0.85` | `>= 0.92` |
| 方向 macro-F1 | `>= 0.85` | `>= 0.92` |
| onset/offset 中位绝对误差 | `<= 0.75 s` | `<= 0.50 s` |
| 最差来源 F1 | `>= 0.75` | `>= 0.85` |
| 跌倒/弯腰/蹲下困难负例误报率 | `< 10%` | `< 5%` |

### 6.6 必做消融

- clip 分类与连续事件定位对照。
- 单一 presence 头与多任务 phase/direction/quality 头对照。
- 不使用腕部与使用腕部支撑特征对照。
- 不使用时长/稳定时间与加入这些特征后的融合增益。
- NTU 内部结果与跨来源结果并排展示。

## 7. 模型三：个体行为基线模型

### 7.1 训练目标

判断同一老人近期步态、坐站、近跌倒频率和活动节律是否相对个人历史发生异常变化。该模型是比赛中“连续感知”和“前置预判”的核心创新点。

### 7.2 事实限制

当前只有滚动统计规则，没有可用于纵向监督训练的风险标签。个体基线不能用不同公开数据集中的不同人拼成伪时间序列，也不能用现有规则输出作为真值再证明规则有效。

### 7.3 数据设计

每条训练样本以 `person_id + day` 为单位，至少包含：

- 日均步态风险、步速变化、对称性和转身稳定性。
- 坐站次数、平均持续时间、失败尝试和稳定时间。
- 近跌倒次数、最高分和距离最近事件的时间。
- 活动量、夜间活动和场景分布。
- 数据质量、有效观测时长和缺失比例。
- 独立参考：重复功能评估、专家复核的状态变化或后续近跌倒/跌倒结局。

比赛最低目标为不少于 20 名参与者、每人连续 14 天；更理想的是 30 天以上。若提交前无法获得该规模，模型只能作为小样本可行性实验，不能宣称预测真实跌倒风险。

### 7.4 实验矩阵

| 实验 | 模型 | 目的 |
|---|---|---|
| B0 | 群体固定阈值 | 证明个体化是否必要 |
| B1 | 个人 rolling mean/std | 当前 baseline |
| B2 | Median/MAD + EWMA/CUSUM | 小样本稳健主模型 |
| B3 | 混合效应模型 | 同时利用群体先验和个人偏移 |
| B4 | TCN/GRU 自编码器 | 数据量足够时学习正常行为序列 |
| B5 | B2 + B4 集成 | 只在异常互补且误报下降时保留 |

B2 为比赛主线。B4 只有在可用正常 person-day 超过 1,000 且至少覆盖 30 人时启动，否则深度异常模型很容易记住人员和缺失模式。

### 7.5 内部冲奖目标

| 指标 | 最低保留线 | 冲奖目标 |
|---|---:|---:|
| 已知状态变化 Recall | `>= 0.75` | `>= 0.85` |
| 变化检测 F1 | `>= 0.65` | `>= 0.75` |
| 正常期误报 | `< 0.20/人日` | `< 0.10/人日` |
| 相对群体阈值 F1 增益 | `>= 3 pp` | `>= 8 pp` |
| 中位提前量 | `> 0` | `>= 1 天` |

没有真实时间顺序和独立状态变化标签时，不计算“提前量”。

### 7.6 必做消融

- 群体阈值与个人阈值。
- rolling statistics 与 EWMA/CUSUM。
- 去掉步态、坐站、近跌倒、活动节律中的每一项。
- 去掉基线污染保护，观察异常日进入参考窗口后的性能变化。
- 3 天、7 天、14 天和 30 天历史窗口敏感性。

## 8. 模型四：跌倒风险融合模型

### 8.1 训练目标

把步态、坐站、近跌倒、个人基线、场景、活动节律和质量信息融合为 `risk_score` 与 0-4 级风险，重点提高 3-4 级高风险 Recall，同时控制每人每天误报数量。

### 8.2 当前硬阻塞

[`data/annotations/fall_risk/risk_labels.jsonl`](../../../../data/annotations/fall_risk/risk_labels.jsonl) 当前为 0 条。没有与上游特征按同一人员、同一时间配对的独立风险标签，Logistic、EBM、LightGBM 或神经融合模型都无法进行有效监督训练。

不得把“跌倒 TCN 高分”直接当作最终风险标签。跌倒动作识别回答已经发生了什么，风险融合要回答未来短期风险和当前综合风险，两者不是同一个目标。

### 8.3 标签与样本单位

主任务采用 `person_id + day` 或固定时间窗作为样本，标签包括：

- 专家复核的 `risk_level=0..4`。
- 二分类主终点：`high_risk = risk_level >= 3`。
- 可选前瞻终点：未来 24 小时或 7 天是否发生近跌倒/跌倒。
- 标签依据和置信度，避免把不确定样本强行写成确定等级。

每条样本必须同时具备上游分支值、可用性 mask 和独立标签。公开跌倒视频、功能评估数据和长期个人数据如果不是同一批人员，不得拼接成一条“多模态”训练样本。

### 8.4 实验矩阵

| 实验 | 模型 | 目的 |
|---|---|---|
| F0 | 当前规则评分卡 | 可解释 baseline |
| F1 | L1/L2 Logistic | 最低复杂度监督基线和校准参照 |
| F2 | EBM | 可解释非线性主候选 |
| F3 | LightGBM | 非线性交互主候选 |
| F4 | 小型缺失感知 MLP | 验证深度融合是否有必要 |
| F5 | F2/F3 校准集成 | 仅在稳定增益时保留 |

优先在 EBM 和 LightGBM 中选择比赛主模型。样本量低于 1,000 个独立 person-day 时，不启动 MLP；样本量低于 300 时，以 Logistic/规则为主，不把树模型高训练分数当作提升。

### 8.5 内部冲奖目标

| 指标 | 最低保留线 | 冲奖目标 |
|---|---:|---:|
| 普通风险分类 Accuracy | `>= 0.80` | `>= 0.85` |
| 高风险 Recall | `>= 0.85` | `>= 0.90` |
| 高风险 F1 | `>= 0.75` | `>= 0.82` |
| 高风险 PR-AUC | `>= 0.80` | `>= 0.88` |
| Macro-F1（0-4 级） | `>= 0.65` | `>= 0.75` |
| ECE | `<= 0.10` | `<= 0.05` |
| 高风险误报 | `< 0.20/人日` | `< 0.10/人日` |

Accuracy `0.85` 和高风险 Recall `0.90` 与现有冲奖目标一致，但必须建立在独立 `risk_labels` 上。

### 8.6 比赛关键消融

在同一批配对 person-day 上依次比较：

```text
F0  仅跌倒事件
F1  + 近跌倒
F2  + 步态
F3  + 坐站
F4  + 个体基线
F5  + 场景与活动节律
F6  + 质量 mask 与拒识
```

答辩重点展示 `F4 - F3`，即加入个人基线后高风险 Recall、误报/人日和提前量的变化。这是证明作品不是普通跌倒检测器的最关键数字。

## 9. 统一评价与比赛展示

### 9.1 必报指标

| 层级 | 主指标 | 辅助指标 |
|---|---|---|
| 步态/坐站事件 | Recall、F1、PR-AUC | Balanced accuracy、误报/小时、边界误差 |
| 个体基线 | 变化 Recall、误报/人日、提前量 | F1、检测延迟、历史窗口敏感性 |
| 风险融合 | 高风险 Recall、PR-AUC、Macro-F1 | Accuracy、ECE、Brier、误报/人日 |
| 场景鲁棒性 | 最差场景 F1、跨来源下降 | 白天/夜间、遮挡、视角、助行器分层 |

### 9.2 必须形成的图表

- 四类模型统一效果总表：规则、轻量模型、增强模型、最终选择。
- PR 曲线与阈值-Recall-误报曲线。
- 混淆矩阵，特别标出高风险漏报。
- 分来源、分场景、分视角柱状图。
- 个人风险时间轴：步态/坐站变化、近跌倒事件、基线偏离和最终风险分同图展示。
- 融合消融瀑布图：逐项加入近跌倒、步态、坐站和个人基线后的指标变化。
- 失败案例册：每类至少展示一个误报和一个漏报，并说明下一步数据补强方向。

### 9.3 比赛演示脚本对应的模型证据

1. 正常行走与正常坐站：低风险、不误报。
2. 连续慢走或拖步：步态分支升高，但没有直接触发跌倒紧急告警。
3. 多次起身困难：坐站能力分支升高。
4. 近跌倒后恢复：近跌倒模型触发，融合风险升级。
5. 同一老人连续多日恶化：个人基线比群体阈值更早发现变化。
6. 真实跌倒：现有跌倒 TCN 触发最高级即时事件。

比赛材料不能把六段不同人员的视频剪成一个虚构的纵向个体案例。个人基线演示必须来自同一 `person_id` 的真实或明确标记为合成的连续序列。

## 11. Go/No-Go 决策

### 11.1 步态

- Go：新增独立正例后，主模型 Recall、F1 和误报同时达到最低线。
- No-Go：只有 accuracy 上升，或通过大量误报换取 Recall；比赛主线改用 EBM/规则。

### 11.2 坐站

- Go：连续事件 F1 与边界误差达标，最差来源明显改善。
- No-Go：仍只能在预裁剪 NTU clip 上高分；只作为功能演示，不宣称连续识别。

### 11.3 个体基线

- Go：同一人员纵向数据上优于群体阈值，并降低误报或提供提前量。
- No-Go：没有同一人员连续数据或独立状态变化参考；保留统计 baseline，不训练自编码器。

### 11.4 风险融合

- Go：有非空配对 `risk_labels`，且 EBM/LightGBM 在高风险 Recall、PR-AUC、校准或误报上稳定优于规则。
- No-Go：风险标签仍为空、由规则自生成或样本不配对；比赛中展示规则融合，不声称训练了风险模型。

## 12. 最终提交应回答的问题

最终专项研究报告需要用模型结果直接回答：

1. 相比单纯跌倒动作检测，步态、坐站、近跌倒和个人基线分别增加了什么前置信号？
2. 每个模型相对规则 baseline 提升了多少，是否在不同场景和来源上成立？
3. 高风险 Recall、误报率和提前量分别是多少？
4. 去掉个人基线后，融合模型效果下降多少？
5. 哪些错误仍然存在，模型在哪些居家场景下会拒绝判断？

如果四个模型全部完成，比赛创新叙事应是：

> 系统不是只在老人倒地后报警，而是通过步态稳定性、坐站能力、近跌倒恢复和个人纵向变化构建分层风险证据，再由可解释融合模型输出前置风险等级；跌倒 TCN 负责即时安全事件，个人基线和风险融合负责前置预判。

这比继续增加一个更大的跌倒动作分类器更符合赛题要求，也更容易在终审中通过消融、时间轴和场景实测证明实际增益。
