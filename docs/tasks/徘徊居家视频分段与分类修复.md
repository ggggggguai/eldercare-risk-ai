## 4. 已确认根因

1. 主轨迹多数连续且高置信，漏段主要发生在后续运动状态机，不是 YOLO 未检出。
2. 现行起步规则要求连续 5 个 0.5 秒 bucket 的累计路径达到 0.25 body-height，慢走、远景和短直行容易漏检；累计微小位移又会放大静止框抖动。
3. 4 秒 stationary closing 会切碎含短暂停顿的连续行为；`stationary_candidate_drift` 和视频结束会把已有分类结果的 proposal 标为 uncertain。
4. `rejected_by_qc` 不送模型；已成段的短片还可能被 episode QC 以 `insufficient_motion` 二次拒绝。
5. `wand_H01_base_2` 的 oracle 小段均可判 direct，自动长段判 lapping，说明该问题首先来自过度合并。
6. pacing 在 oracle 完整边界下仍会被判 lapping/random，必须独立修复 subtype，不能只调分段器。
